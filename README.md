## Что такое «Классик»

Каждый день тысячи людей ищут коды из официальных справочников: чтобы заполнить декларацию, оформить закупку, зарегистрировать бизнес, посчитать амортизацию, указать валюту в договоре. Официальные документы есть, но искать в них нужную строчку долго и неудобно.

## Как пользоваться

**1. Открыть нужный справочник.** На главной странице — 14 карточек. Можно нажать на код в панели быстрого перехода сверху и сразу попасть к нужной карточке.

**2. Найти код.** В каждом справочнике есть поиск: по коду, по названию, по ключевым словам. Поиск по коду — префиксный: если ввести `56`, найдутся все коды, начинающиеся на 56, включая `56.10`, `56.10.1` и т. д.

**3. Скопировать.** Клик по коду в карточке — и код уже в буфере обмена. Кнопка `📋 строка` копирует целую строку для вставки в документ. Кнопка `📤 Поделиться` отправляет ссылку коллеге или клиенту.

**4. Вернуться.** В каждом справочнике внизу слева есть кнопка «← Классик» — возвращает на главную витрину.

## Не путать

Несколько пар справочников, которые часто путают. Это самая частая причина ошибок в документах.

- **ОКПД2 ≠ ОКВЭД2.** ОКПД2 — что производится или продаётся (товары, услуги). ОКВЭД2 — чем занимается организация (виды деятельности).
- **ОКТМО ≠ ОКАТО.** Для налогов, бюджетных платежей и муниципальных услуг нужен **ОКТМО**. ОКАТО с 2014 года почти везде заменён.
- **ОКЗ ≠ ОКСО.** ОКЗ — кем человек работает. ОКСО — что он закончил.
- **ОКВ ≠ ОКСМ.** ОКВ — в какой валюте. ОКСМ — какая страна.
- **ОКОФ ≠ ОКПД2.** ОКОФ — имущество, которое используется как средство труда (здания, оборудование, транспорт). ОКПД2 — продукция, которая производится или продаётся.

Если сомневаетесь — начните с ОКПД2 для товаров и услуг, с ОКВЭД2 для деятельности организации, с ОКТМО для адресов и налогов.

## Частые вопросы

**Что такое «Классик»?**
Это сайт-витрина общероссийских классификаторов. Все справочники в одном месте, устроены одинаково, работают без регистрации и без установки.

**Нужно ли регистрироваться?**
Нет. Сайт работает без аккаунта, без подписки, без смс. Открыли, нашли, скопировали.

**Откуда данные?**
Из официальных источников — Росстата, Минюста, порталов открытых данных, текстов нормативных актов. Справочники обновляются автоматически по мере выхода новых редакций.

**Сколько стоит?**
Бесплатно. Проект существует для удобства тех, кто работает с классификаторами каждый день.

**Как найти код, если не знаю, в каком справочнике искать?**
Откройте карточку нужного справочника по сфере (закупки / бизнес / территория / люди), затем воспользуйтесь поиском. Если совсем не уверены — начните с ОКПД2 для товаров, ОКВЭД2 для деятельности, ОКТМО для адресов.

**Что такое ПП 1875?**
Постановление Правительства РФ № 1875 от 23 декабря 2024 года о национальном режиме в закупках. Справочник показывает, какие ограничения действуют для конкретного кода ОКПД2. Отдельный справочник, в паре с ОКПД2.

**Нашёл ошибку. Куда писать?**
Напишите в ВК-сообщество (ссылка ниже) или напрямую в любой из каналов связи. Укажите справочник, код и что не так — поправим.

**Можно ли использовать данные в своих программах?**
Да. Данные на сайте — это открытые сведения из официальных классификаторов. Их можно использовать в учётных системах, приложениях, отчётах.

## Дисклеймер

Справочники носят **справочный характер**. Они помогают быстро найти нужный код и подготовить документ, но **не заменяют официальные первоисточники**: постановления Правительства, приказы Росстандарта, тексты классификаторов в действующей редакции.
